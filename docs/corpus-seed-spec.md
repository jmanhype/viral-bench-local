# Corpus Seeding Spec

## Goal
Seed the research corpus with 50+ TikTok handles across verticals to build a useful UGC knowledge base.

## How
POST to http://127.0.0.1:8001/v1/seed with batches of handles. The scraper caches profiles so repeated calls are fast.
